# Build an app on BaseHero

## What you get

Learn how an app uses BaseHero's encrypted data, sync, and models.

## Add the core

Prepare your Rust project and its native dependencies to embed the core.

## Open the core

Set up the app's data directory and protect its local secrets.

## Connect

Connect your app to a person's chosen bases on Android or from the command line.

## What your app can see

Understand what access to a granted base includes.

## Record types

Define and evolve the types your app writes.

## Write and query records

Create, update, find, and delete records, and respond to changes.

## Sync and offline

Keep local work usable while the network is unavailable.

## Bulk data

Choose a suitable record layout for larger collections of measurements.

## Models

Call models on behalf of an account through BaseHero.

## Test against `dev`

Use the development environment to try your integration.

## Stability

Learn which interfaces stay compatible and how to pin a core release.
