# Native confidential host adapters (Unix only)

`TimeSampler` is a boot-local, shareable async UDP adapter for `bh-qualified-time`. Trusted caller code passes exactly two different numeric `SocketAddr` endpoints with distinct pinned `ServerRoot` keys, the qualified clock's `Config`, a nonzero finite total timeout, and an existing `Counter` on each `refresh` / `now` call. There are no default hosts, DNS, discovery, proxy, HTTP, fallback or retries. Each concurrent request sends a cryptographically random fresh 64-byte nonce in a canonical 1024-byte Google-Roughtime v1 packet; counter readings surround each actual transport send/receive. A connected socket uses the endpoint's IP family, and a 4097-byte receive buffer detects datagrams exceeding the 4096-byte signed-reply limit, even when a truncated 4096-byte prefix would verify. Both signed nonce-bound intervals must qualify through the pure library before returning its conservative `Bounds`. One timeout covers **both** concurrent queries and verification. A second simultaneous `refresh` returns the fixed `TimeError` without invalidating the first refresh. Acquisition holds no clock-state lock; during it, `now` can use the prior anchor only within its original age and width bounds. Successful acquisition installs the new pair atomically under a short synchronous lock; failure, timeout, late synchronous completion and cancellation after refresh begins invalidate the preceding anchor. The counter used for `now` and installation is read under that lock to serialize rollback checks. One clock instance holds a bounded nonce history, so after `TimeSampler::REFRESHES_PER_CLOCK` successful refreshes the next refresh replaces it under that lock before installing: one counter reading seen by both clocks carries the rollback floor, a clock that has seen a rollback is never replaced, and the new clock holds only that refresh's pair, or none if it fails. Errors contain no addresses, packet contents, OS/library text or proof data.

Different pinned keys alone do not establish independent operators. This adapter has no scheduler, trusted oscillator implementation, host qualification or service-readiness claim. The caller must justify the counter's rate, drift and pause behavior and choose all configuration limits before using time for authority. `now` retains the pure library's stale/rollback/width behavior. Tests exercise two synthetic signed loopback UDP fixtures, not a public time server or real VM counter.

## Quote acquisition

`QuoteSocket` accepts an explicitly trusted local dstack guest-agent Unix socket path. `get_quote` sends the exact 64 bytes from `bh_confidential_attestation::report_data` as hex JSON to fixed `POST /GetQuote`, with no SDK rehash, TCP/DNS/proxy/redirect fallback, automatic socket discovery, credentials or retry. The caller supplies public signing/receiving keys, its own fresh verifier nonce and a finite total deadline. No private keys or jobs are retained. The return type is `UnverifiedQuote`: these are raw quote and event-log bytes, **not** an authenticated hardware proof, authorization or service-ready flag. The caller still acquires collateral and trusted time and invokes offline verification, checks signed policy, channel key possession and current authority separately.

The aggregate HTTP body limit is 8 MiB + 4096 bytes: up to 1 MiB raw quote expands to 2 MiB hex; up to 1 MiB event-log UTF-8 can expand to 6 MiB JSON Unicode escapes; 4096 bytes cover framing and optional public metadata. Individual decoded fields are capped at the offline verifier's 1 MiB input bound. Real host response sizes are unmeasured; revise deliberately if legitimate responses exceed this ceiling. Even a successful local mock is not a matched fresh Intel quote. Only native Unix builds use this module; portable libraries and Wasm interfaces do not depend on it.

Schema source: retained dstack revision `4699c48` in `sdk/rust/src/dstack_client_v0.rs` (`get_quote`, `/GetQuote`, hex `report_data`), `sdk/rust/types/src/dstack_v0.rs` (`GetQuoteResponse`: hex `quote`, string `event_log`, optional `report_data`/`vm_config`), and `dstack/guest-agent/src/rpc_service.rs` (`get_quote` calls `pad64` on raw request bytes). Tests use isolated local Unix HTTP fixtures; no hardware endpoint or public network is contacted.
