# Local Worker crypto fixture

From `basehero/`, run `bash scripts/check.sh wasm-crypto` to build the
root-pinned target libsodium static archive, compile this Rust `cdylib` for
`wasm32-unknown-unknown` and run it as a compiled Wasm module inside local
Miniflare/workerd. The npm lock pins that local runtime. `probe.wasm`,
`node_modules/` and the temporary workerd cache are generated locally.

The exported `check_crypto()` checks BLAKE2b-256 of empty input and an
independent Python `hashlib` vector for `abc`, and rejects the same digest for
`abd`. It also uses a fixed Ed25519 signature generated by native `bh-crypto`
using seed `[7; 32]` and message `message`, rejecting changed message and
signature. No signing key is
shipped into the Worker. This fixture is not the sync checker; service
integration is separate. Runtime import policy lives in
`libs/crypto/worker-host.mjs`, and
the linker may import only `allowed-imports.txt`. Unsupported C heap APIs are
not a passing Worker path.
